# Mahila Atyachar Nivaran Samiti - Official Website

This repository contains the source code for the official website of the Mahila Atyachar Nivaran Samiti, a non-governmental organization dedicated to women's welfare and protection in India.

## About the Project

This website is built using **HTML5, CSS3, and vanilla JavaScript** only, with no external frameworks. It is designed to be:

- **Elegant & Modern:** A professional design that reflects the organization's mission.
- **Responsive:** Fully accessible on all devices (desktops, tablets, and mobile phones).
- **Fast & Secure:** Optimized for performance and security best practices.
- **SEO-Friendly:** Structured for high visibility on search engines.
- **Accessible:** Built to be usable by people with disabilities (WCAG compliant).
